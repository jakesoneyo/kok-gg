## 화면 구성 (시안 기준)

1. 헤더: 로고 `kok.gg`(점만 액센트), 필 내비(트렌딩/카탈로그/검색/북마크), 다크 필 로그인 버튼
2. 히어로: "이런 거 있어?" 자연어 검색(이중 베젤 입력) + 예시 질의 칩 3개, 우측 통계 카드(오늘 신규·위험 등급 항목) + 데모 로그인 카드(`회원가입 없이 둘러보기` / `회원가입 없이 체험해 볼 수 있습니다.`)
3. 트렌딩: 기간 세그먼트(1일/7일/30일), 정렬 칩 4종, 종류·등급 필터 세그먼트, 순위 목록(순위 변동·종류·요약·총 스타·**7일 증가량 강조**·7일 스파크라인·등급 배지·북마크)
4. 상세 미리보기: 30일 스타 차트, 한국어 요약 + "README 원문 인용" 코드블록, 위험 신호 목록(규칙명·`file:line`·스니펫·설명), 면책 문구, 오탐 신고 링크
5. 푸터: 데이터 출처 / 방법론
